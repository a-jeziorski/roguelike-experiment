# Dust Crossing — Dungeon Bible

*Brief by design, like `docs/dungeon_bibles/fallen_colonnade.md` before it -
the second of a short run of small dungeons exercising `tools/procgen/`
against real, shipped content, one per algorithm, per
`docs/region_bibles/dust_reach.md`'s plan.*

## What it is

A single-level, peaceful, non-progression place (`requires_stairs_down:
false`, matching `data/dungeons/millhaven`'s shape) generated by
`tools/procgen/road_network.py`: a network of `road` tiles grown outward
from a central point over open `plains`, four spokes plus branches. No
buildings - the generator only ever draws roads, per its own docstring
("footprint placement for those is a later, bible-driven authoring pass").
The whole field is framed by a `wall` border (`tools.procgen.base.frame_border`,
applied after generation so every hand-built test dungeon in this run
reads as an enclosed space rather than terrain that just stops at the map
array's edge - see that function's docstring) with a single gap serving
as the gate.

**Era**: Settlers, Long Quiet present day - but a step earlier than an
actual settlement. This isn't Millhaven or Wayford with walls, buildings,
and people; it's the roads someone's already worn into the ground by
walking this far out repeatedly, plus enough stacked stone around the
perimeter to mark the ground as claimed, without anyone having built
anything here yet. Read it as the leading edge of Dust Reach's present-day
traffic (plausibly connected to Farrow's Stake's own trade-spur ambitions,
per `docs/world_history.md`'s Geography section, though this document
doesn't commit to that link explicitly) - a place a future pass could turn
into a real settlement, not one that already is one.

## Roster

None. Zero entities, zero items, matching every other test dungeon in this
run - the point is exercising the generator and the content pipeline.

## Layout notes

- `player_start` sits at the road network's own center (where all four
  spokes meet); the exit - a `stairs_up` styled as "the way back out onto
  Dust Reach" (`requires_stairs_down: false`, no `open_boundary`, the same
  terminal-stairway pattern Millhaven's own town-gate tile uses) - sits in
  the boundary wall itself, at a gap adjacent to a road tile that
  originally reached the edge before framing.
- Inside the wall, `plains` is still fully walkable - the roads there are
  purely a visual/flavor distinction (packed dirt vs. open ground), not a
  navigation constraint. The boundary itself is the only real wall in the
  level.

## Tone notes

- Don't add buildings or NPCs here without a real reason - this dungeon's
  identity is specifically "not settled yet." If a future pass wants to
  turn Dust Crossing into an actual settlement, that's a deliberate
  decision, not something this document already assumes.

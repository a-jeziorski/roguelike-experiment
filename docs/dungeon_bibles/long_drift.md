# The Long Drift — Dungeon Bible

*Brief by design, the eighth of a short run of small dungeons exercising
`tools/procgen/` against real, shipped content, one per algorithm, per
`docs/region_bibles/dust_reach.md`'s plan.*

## What it is

A single-level dungeon (`data/dungeons/long_drift/levels/level_01.lvl`,
45x30) generated by `tools/procgen/drunkards_walk.py`: three random
walkers, the first starting at the grid's center and each later one
starting from an already-carved tile, wandering a 4-directional random
walk and carving floor as they go. The result is narrow, winding, purely
organic tunnels with no straight walls anywhere - visually distinct from
every structured algorithm in this run (BSP, room accretion, maze), and
from DLA's branching dendrites and cellular automata's smooth blobs too
(see `docs/procgen_algorithms.md`'s drunkard's walk section for the
generator itself).

**Era**: Fallen Old Kingdom infrastructure, unclaimed - the same category
`fallen_colonnade` belongs to (see `docs/world_history.md`'s roster). A
mining tunnel, not a mine complex like `sunken_mine` - a different seam,
a different crew, unrelated to that site and forgotten the same way.

## Roster

None. Zero entities, zero items - the point of this pass is exercising
the generator and the content pipeline, not a combat encounter.

## Layout notes

- The generated grid is framed with `tools.procgen.base.frame_border`
  before anything else - a walker's random walk can reach the true grid
  edge with no cap the way DLA's interior-radius does, so framing matters
  here more than for most other algorithms in this run.
- `player_start` and the single terminal `stairs_down` sit at the two
  floor tiles `tools.procgen.base.farthest_pair` found furthest apart (by
  8-directional graph distance) within the level's largest connected
  component (computed *after* framing).
- Every walker starts on already-carved floor, so the whole tunnel network
  is one connected graph by construction - never an isolated pocket.
- No `next_level` - reaching the stairs leaves the dungeon and returns
  directly to Dust Reach, matching this run's other terminal single-level
  dungeons.

## Tone notes

- Keep this empty and unexplained, the same restraint `sunken_mine` and
  `silver_mountain_caves` extend to their own origins - there's no
  mystery to solve here, just a played-out seam nobody bothered to
  reclaim.
- If a future pass wants to give this tunnel actual current occupants,
  that's a deliberate follow-up, not something this document already
  assumes.

# The Ledger Hall — Dungeon Bible

*Brief by design, the tenth and last of a short run of small dungeons
exercising `tools/procgen/` against real, shipped content, one per
algorithm, per `docs/region_bibles/dust_reach.md`'s plan. With this one,
every algorithm in `tools/procgen/` has a real test dungeon in Dust
Reach.*

## What it is

A single-level dungeon (`data/dungeons/ledger_hall/levels/level_01.lvl`,
45x30) generated by `tools/procgen/bsp_rooms.py`: a recursive rectangular
partition of the grid down to a minimum leaf size, one room carved per
leaf, sibling partitions connected by real 90-degree-bend corridors as
the recursion unwinds. Straight walls, rectangular rooms in rows, right-
angled turns throughout - the one algorithm in this run whose rooms come
from a strict recursive partition, distinct from Voronoi's raster diagram
and room accretion's unstructured scatter (see
`docs/procgen_algorithms.md`'s BSP section for the generator itself).

**Era**: Old Kingdom's remnants, the same category `prison_tower` and
`tangle_lock` belong to (see `docs/world_history.md`'s roster) - a
deliberately planned building, not a ruin something else moved into or a
natural formation. Whatever records it kept are unstated.

## Roster

None. Zero entities, zero items - the point of this pass is exercising
the generator and the content pipeline, not a combat encounter.

## Layout notes

- The generated grid is framed with `tools.procgen.base.frame_border`
  before anything else - a room in an edge partition cell can otherwise
  sit flush against the grid's own boundary.
- `player_start` and the single terminal `stairs_down` sit at the two
  floor tiles `tools.procgen.base.farthest_pair` found furthest apart (by
  8-directional graph distance) within the level's largest connected
  component (computed *after* framing).
- Every pair of sibling partitions is corridor-connected as the
  generator's own recursion unwinds, so the whole building is one
  connected graph by construction - never an isolated room.
- No `next_level` - reaching the stairs leaves the dungeon and returns
  directly to Dust Reach, matching this run's other terminal single-level
  dungeons.

## Tone notes

- Keep this genuinely empty and unexplained, the same restraint every
  other test dungeon in this run extends to its own origin - there's no
  mystery to solve here, no ledger to find.
- If a future pass wants to give this building actual current occupants
  or contents, that's a deliberate follow-up, not something this document
  already assumes.

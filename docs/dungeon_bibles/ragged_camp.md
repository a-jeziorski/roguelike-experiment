# The Ragged Camp — Dungeon Bible

*Brief by design, the seventh of a short run of small dungeons exercising
`tools/procgen/` against real, shipped content, one per algorithm, per
`docs/region_bibles/dust_reach.md`'s plan.*

## What it is

A single-level dungeon (`data/dungeons/ragged_camp/levels/level_01.lvl`,
45x30) generated by `tools/procgen/room_accretion.py`: random-sized
rectangular rooms scattered at random positions via rejection sampling
(no overlap, plus a buffer margin), each newly-placed room corridor-
connected to its nearest already-placed neighbor. The result is a
collection of real, walled rectangular rooms at irregular spacing and
size - never derived from any underlying partition of the grid the way
BSP's or Voronoi's rooms are (see `docs/procgen_algorithms.md`'s room
accretion section for the generator itself).

**Era**: Opportunists - the first test dungeon in this run to use that
category (see `docs/world_history.md`'s roster: `broken_watch`,
`the_windrest`). Unlike those two, this wasn't fallen Old Kingdom
infrastructure someone moved into - there was nothing here to squat, so
whoever held this ground built their own rooms instead, unmatched and
purely practical, the same instinct without the ready-made shelter.
They've since moved on; the rooms are empty.

## Roster

None. Zero entities, zero items - the point of this pass is exercising
the generator and the content pipeline, not a combat encounter.

## Layout notes

- The generated grid is framed with `tools.procgen.base.frame_border`
  before anything else - room accretion's own rejection sampling keeps
  rooms at least 1 tile from the edge by construction, but framing is
  still applied for consistency with every other algorithm in this
  library.
- `player_start` and the single terminal `stairs_down` sit at the two
  floor tiles `tools.procgen.base.farthest_pair` found furthest apart (by
  8-directional graph distance) within the level's largest connected
  component (computed *after* framing).
- Every room is corridor-connected to its nearest already-placed
  neighbor at generation time, so the whole level is one connected graph
  by construction - never an isolated room a player couldn't reach.

## Tone notes

- Keep this genuinely abandoned - no lingering occupants, no loot to
  imply anyone left in a hurry. If a future pass wants to give this camp
  actual current inhabitants, that's a deliberate follow-up, not
  something this document already assumes.

# The Tangle Lock — Dungeon Bible

*Brief by design, the sixth of a short run of small dungeons exercising
`tools/procgen/` against real, shipped content, one per algorithm, per
`docs/region_bibles/dust_reach.md`'s plan.*

## What it is

A single-level dungeon (`data/dungeons/tangle_lock/levels/level_01.lvl`,
45x29) generated by `tools/procgen/maze.py`'s recursive-backtracker
carving: a perfect maze (exactly one path between any two cells) with a
light `braid=0.15` pass afterward knocking a few dead ends into loops, so
it reads as deliberately confusing rather than a strict, sterile puzzle
(see `docs/procgen_algorithms.md`'s maze section for the generator
itself). Rectilinear, right-angled corridors throughout - visually
distinct from every other test dungeon in this run.

**Era**: Old Kingdom's remnants, the same category `prison_tower` belongs
to (see `docs/world_history.md`'s roster) - a deliberately-laid-out
security structure, not a ruin something else moved into. Whatever it
once guarded is unstated; this document doesn't invent a specific answer.

## Roster

None. Zero entities, zero items - the point of this pass is exercising
the generator and the content pipeline, not a combat encounter.

## Layout notes

- `player_start` and the single terminal `stairs_down` sit at the two
  floor tiles `tools.procgen.base.farthest_pair` found furthest apart (by
  8-directional graph distance) within the level's largest connected
  component.
- The maze generator's own output is already enclosed on every side by
  construction (an odd width/height leaves a solid wall column/row past
  the last cell) - `frame_border` is still called at the end of
  `generate` itself for consistency with every other algorithm in this
  library, not because this one specifically needed it.
- No `next_level` - reaching the stairs leaves the dungeon and returns
  directly to Dust Reach, matching this run's other terminal single-level
  dungeons.

## Tone notes

- Keep the "what did this guard" question unanswered, the same way the
